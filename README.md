# 🎮 Trivia Blitz

Juego de trivia interactivo con sistema de combos y puntuación. Proyecto desarrollado para Tecnologías Web I.

## 🚀 Características

- ✅ Autenticación de usuarios
- ✅ Preguntas de trivia con múltiples opciones
- ✅ Sistema de combos para puntuación bonificada
- ✅ Registro de resultados y estadísticas
- ✅ Interfaz responsiva con Bootstrap
- ✅ Integración con Firebase

## 🛠️ Tecnologías

- **Frontend**: React 19, Vite, Bootstrap 5
- **Backend**: Firebase (Autenticación y Base de Datos)
- **Estilos**: CSS3, Bootstrap Icons
- **Enrutamiento**: React Router DOM
